# 仕様書 — Life-Log & Focus

## 1. プロジェクトの理念

| 原則 | 内容 |
|------|------|
| 認知リソースの解放 | ワーキングメモリーの負荷を下げるため「即時書き出し」を最優先 |
| 心理的安全性 | 生座標を保存せず「ラベル」として記録。監視感を排除 |
| メタ認知の自動化 | AIが構造的フィードバックで思考バイアスや行動パターンを発見を促す |

## 2. 機能仕様

### ① つぶやき（思考のデフラグ）

**日中（05:00〜17:59）の入力ステップ**
1. 自由記述テキスト
2. 場所ラベル: 自宅 / 職場 / カフェ / 移動中 / その他
3. 天気: ☀️ / ☁️ / ☔️ / 🌀（低気圧）

**夜間（18:00〜04:59）の追加ステップ**
4. 今日の点数（20〜100）
5. 点数の理由（任意）

**タスク自動検知**
- つぶやきテキストに `□` または `todo` が含まれる場合、タスク候補を抽出しリスト追加を提案

### ② タスク整理（実行の構造化）

- **一覧表示**: 未完了タスクを番号付き箇条書きで表示
- **追加フロー**: AIが「次は何をする？」と問いかけ → 改行区切り入力 → 個別タスクに分割登録
- **完了**: 番号入力でタスクを完了状態へ
- **削除**: 番号入力でタスクをリストから削除

### ③ 振り返り（多角的な期間分析）

**対象期間**: 今週 / 今月 / 今年（データ不足時は「現時点まで」として処理）

**レポート構造**:
1. **事実** — つぶやき要約（キーワード + 代表的なつぶやき引用）
2. **データ分析** — 場所別/天気別の記録数と平均点
3. **AIの気づき** — パターン・バイアスの指摘（根拠となる日付・単語を必ず引用）

**フィードバックループ**: レポート末尾に「違和感はありますか？」を提示

### ④ 設定（パーソナライズ）

| モード | 特徴 |
|--------|------|
| 🌸 優しいモード | 肯定的・情緒的な言葉遣い。共感を重視 |
| 📊 丁寧モード | 論理的・データ重視。簡潔で客観的 |

## 3. データ処理ロジック

| 項目 | 処理内容 | 目的 |
|------|----------|------|
| 位置情報の抽象化 | 生座標を保存せず「ラベル」として記録 | プライバシー保護と環境属性の抽出 |
| タスクの自動検知 | `□` / `todo` キーワードを正規表現で抽出 | 記録と管理のシームレスな統合 |
| 時間帯メッセージ | 朝は「頑張りましょう」、夜は「お疲れ様」 | 儀式化によるセルフケア |

## 4. ハルシネーション対策

1. **事実と推論の分離**: 「要約（事実）」と「分析（推論）」を明確に分けたレイアウト
2. **根拠引用の義務化**: サマリー内で必ず具体的な日付・単語を引用形式で表示
3. **フィードバックループ**: 「内容に違和感はありますか？」でユーザーによる修正を受け付け

## 5. データモデル（SQLite）

### `users` テーブル
| カラム | 型 | 説明 |
|--------|----|------|
| id | TEXT PK | LINE ユーザーID |
| display_name | TEXT | 表示名 |
| tone | TEXT | 口調設定（gentle / formal） |
| created_at | DATETIME | 登録日時 |

### `entries` テーブル（つぶやき）
| カラム | 型 | 説明 |
|--------|----|------|
| id | INTEGER PK | 自動採番 |
| user_id | TEXT FK | LINE ユーザーID |
| body | TEXT | つぶやき本文 |
| location | TEXT | 場所ラベル |
| weather | TEXT | 天気ラベル |
| score | INTEGER | 点数（夜間のみ、NULL可） |
| score_reason | TEXT | 点数の理由（任意） |
| created_at | DATETIME | 記録日時 |

### `tasks` テーブル
| カラム | 型 | 説明 |
|--------|----|------|
| id | INTEGER PK | 自動採番 |
| user_id | TEXT FK | LINE ユーザーID |
| body | TEXT | タスク内容 |
| status | TEXT | todo / done / deleted |
| created_at | DATETIME | 作成日時 |
| completed_at | DATETIME | 完了日時（NULL可） |

### `sessions` テーブル（会話状態管理）
| カラム | 型 | 説明 |
|--------|----|------|
| user_id | TEXT PK | LINE ユーザーID |
| state | TEXT | 現在の会話ステップ |
| context | TEXT | ステップ間で受け渡すJSON |
| updated_at | DATETIME | 最終更新日時 |
