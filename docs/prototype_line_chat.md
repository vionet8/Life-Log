# Life-Log & Focus — LINE トーク画面プロトタイプ

> 凡例  
> 🟢 **Bot** → Botからのメッセージ  
> 🔵 **User** → ユーザー入力  
> `[ボタン]` → タップ可能なクイックリプライ or リッチメニューボタン

---

## ─── 起動 / リッチメニュー ───────────────────────────

```
┌──────────────────────────────────────┐
│  📝 つぶやく   ✅ タスク整理          │
│  📊 振り返り   ⚙️ 設定               │
└──────────────────────────────────────┘
```
> ※ トーク画面下部に常駐するリッチメニュー（4分割）

---

### 【タスク追加フロー】

🔵 User: `[➕ タスクを追加]`

---

🟢 Bot:
```
次は何をしますか？

複数ある場合は改行して入力してください。
（例）
  請求書を送る
  Aさんに返信する
  本を1章読む
```

---

🔵 User:
```
請求書を送る
Aさんに返信する
本を1章読む
```

🟢 Bot:
```
以下を追加しますか？

  ・請求書を送る
  ・Aさんに返信する
  ・本を1章読む
```
クイックリプライ: `[✅ 追加する]` `[✏️ 修正する]` `[✖️ キャンセル]`

```

### 【完了にするフロー】

```

2️⃣ デザインチームに連絡
3️⃣ 週次レポートを提出する
4️⃣ 請求書を送る
5️⃣ Aさんに返信する
6️⃣ 本を1章読む
```

---

🔵 User: `1 4`

---

🟢 Bot:
```
✅ 完了しました！

  ✔ 企画書の最終確認をする
  ✔ 請求書を送る

残り 4件。お疲れ様です 💪

## ─── ④ 設定 ──────────────────────────────────────

🔵 User: `⚙️ 設定`（リッチメニューをタップ）

---

🟢 Bot:
```
⚙️ 設定メニュー

▼ AIの口調を選んでください
（現在：丁寧モード）
```
クイックリプライ: `[🌸 優しいモード]` `[📊 丁寧モード]`

---

🔵 User: `[🌸 優しいモード]`

---

🟢 Bot:
```
口調を「優しいモード」に変更しました 🌸

これからはもっと温かみのある言葉でお話しします。
よろしくね！
```

---

## ─── 【優しいモード vs 丁寧モード】比較 ───────────

| 場面 | 🌸 優しいモード | 📊 丁寧モード |
|------|----------------|--------------|
| 朝の挨拶 | 「おはよう☀️ 今日もいい日にしようね！」 | 「おはようございます☀️ 今日も記録を始めましょう。」 |
| 保存後 | 「記録したよ🌱 あなたの気持ち、ちゃんと受け取った」 | 「✅ 保存しました。内容を確認してください。」 |
| 夜間 | 「今日もよく頑張ったね🌙 ゆっくり休んでね」 | 「お疲れ様でした。今日の振り返りを記録しました。」 |
| 分析 | 「最近、天気が悪い日はちょっとしんどそうだね😌」 | 「曇り・雨の日の平均点は晴れの日より13点低い傾向があります。」 |
